# Blood Bank Management System

A Full Stack Blood Bank Management System developed using Spring Boot, React.js, MySQL, JWT Authentication, and Bootstrap. The application helps manage blood donors, hospitals, blood stock, and blood requests through separate Admin and Public portals.

## Features

### Admin Module

* Secure JWT Authentication
* Dashboard Analytics with Charts
* Donor Management (CRUD)
* Hospital Management (CRUD)
* Blood Stock Management
* Blood Request Approval/Rejection
* Real-time Dashboard Statistics

### Public Module

* Blood Availability Search
* Donor Registration
* Blood Request Submission
* Responsive User Interface

## Tech Stack

### Frontend

* React.js
* Bootstrap
* Axios
* Recharts

### Backend

* Spring Boot
* Spring Security
* JWT Authentication
* REST APIs

### Database

* MySQL
