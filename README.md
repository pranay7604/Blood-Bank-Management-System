# 🩸 Blood Bank Management System

A Full Stack Blood Bank Management System developed using **Spring Boot**, **React.js**, and **MySQL**. The system helps manage blood donors, hospitals, blood inventory, and blood requests through separate **Admin** and **Public** portals.

---

## 📌 Features

### 👨‍💼 Admin Portal

- Secure Admin Login (JWT Authentication)
- Dashboard with Statistics
- Donor Management (CRUD)
- Hospital Management (CRUD)
- Blood Stock Management (CRUD)
- Blood Request Management
- Approve/Reject Blood Requests
- Automatic Blood Stock Update
- Dashboard Analytics
- Blood Group Distribution Chart
- Low Blood Stock Alerts

---

### 🌐 Public Portal

- Home Page
- Blood Availability Search
- Donor Registration
- Blood Request Submission

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/pranay7604/Blood-Bank-Management-System.git
```

### Backend

```bash
cd bloodbank-backend
mvn spring-boot:run
```

### Frontend

```bash
cd bloodbank-frontend
npm install
npm start
```

---

## 🗄 Database Configuration

Update `application.properties`:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/blood_bank_fullstack
spring.datasource.username=YOUR_USERNAME
spring.datasource.password=YOUR_PASSWORD
```
